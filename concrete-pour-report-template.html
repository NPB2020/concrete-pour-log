How to use the template on site

  1. Set up the pour before placement. Enter project, location/element, supplier, mix reference and ordered quantity.
  2. Add one row per delivery. Keep the supplier ticket number as the primary delivery reference.
  3. Record tests when performed. Preserve result, unit and sample reference; do not invent acceptance criteria.
  4. Write issues as factual events. State what happened, what it related to and what action was taken.
  5. Reconcile before closeout. Check truck count, delivered quantity, expected tickets, tests, issues and photos.

Template FAQ

Is the template free?

Yes. The CSV can be downloaded without providing an email address.

Is it an official inspection form?

No. It is a general field-documentation template. Use any project-mandated forms and requirements that apply to your work.

Can I edit it in Excel?

Yes. CSV files can be opened and edited in Excel, Apple Numbers and Google Sheets.
