Note: Result shown here demonstrates report structure only; acceptance criteria are intentionally not stated.

That last point is important: a field report should preserve the measured record without inventing a pass/fail conclusion. ASTM identifies C143/C143M as the standard test method for slump of concrete, while the project documents govern which tests and criteria apply. ASTM concrete standards ↗

Example issue and action record

Issue: Delivery delay
Related delivery: #842371
Observation: Delivery interval longer than preceding sequence; placement paused at Grid B4.
Action: Event recorded and site sequence resumed after delivery arrival.
Evidence: Site photo attached.

A useful issue record answers three questions: what happened, what did it relate to, and what was done. Avoid adding a technical conclusion that was not actually made on site.

What makes this different from a daily report?

A general construction daily report may cover labor, equipment, visitors, weather and multiple activities across the site. A concrete pour report is narrower: it creates a traceable record around one placement and its deliveries, tests, issues and supporting evidence. The two can complement each other.

Report example FAQ

Is this an official ACI or ASTM report form?

No. It is an illustrative field-documentation example created for Concrete Pour Log. Use project-mandated forms where required.

Should a report include photos?

Where useful or required, photos can preserve context for tickets, issues and site conditions. Follow your project requirements.

What if a field was not recorded?

Show that transparently rather than inserting an assumed value.
